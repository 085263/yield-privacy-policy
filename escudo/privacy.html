Escudo プライバシーポリシー

最終更新日: 2026年11月2日

本ポリシーは、個人開発の Android 端末操作補助ツール「Escudo」（以下「本ツール」）における情報の取り扱いを説明するものです。 本ツールは開発者本人のみが自分のアカウント・端末で使用します。

提供者・お問い合わせ先

  • 連絡先メールアドレス: yield.consoleadmin@gmail.com

Google ユーザーデータの利用

本ツールは、開発者本人の Google アカウントについて、Gmail API のスコープ https://www.googleapis.com/auth/gmail.modify の許可を受けて、次の目的にのみ利用します。

  • 受信トレイの未読メールの一覧（差出人・件名・日時・本文の冒頭部分）を取得し、重要なものを選んで本人に知らせる
  • 本人の指示に応じて、メールを既読にする

メールの削除・送信・転送は行いません。

情報の保存と共有

  • 取得したメール情報は、判定のために処理するだけで、データベース等には保存しません。判定結果（重要と判断したメールの要約）は、開発者本人が管理するサーバーの実行ログに一定期間残ることがあります。
  • Google から発行された認可情報（リフレッシュトークン）は、開発者本人が管理するサーバー内のファイルにのみ保存します。
  • 判定のため、メールの一覧情報を AI サービス（Anthropic 社の Claude）に送信します。この情報は広告や第三者への販売には使用しません。
  • 上記以外に、取得したデータを第三者へ提供・販売・共有することはありません。

Google API サービスのユーザーデータに関するポリシーの遵守

Escudo による Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （制限付き使用の要件を含む）に準拠します。

アクセスの取り消し

Google アカウントのサードパーティのアクセス管理から、いつでも本ツールのアクセス権を取り消せます。

改定

本ポリシーを改定する場合は、このページで告知します。
